Selected work

Sonata

Foreign-model subagents for Claude Code.

Claude Code’s subagents always run on Claude. Sonata gives it subagents that run on GPT, DeepSeek, GLM, Kimi or any model you can reach, called through the ordinary Agent tool with the same tools and permission modes.

A local router ranks models per tier and falls back to the next one when a model fails. Open source on npm, in public beta.

Cassette

Record a workflow once. Replay it cheaply.

Programming by demonstration for coding agents. You show a workflow once; Cassette writes a tape that replays deterministically and only calls an LLM for judgement steps or when something breaks, then writes the fix back into the tape.

Federated learning on a microcontroller

My final-year project: a model that trains on a chip with 64 KB of RAM.

Federated learning keeps data on the device and sends only model updates. Flower, PySyft and TensorFlow Federated are too heavy for a board with no operating system, so I wrote my own C++ client: 457.5 kB, against 401.2 MB for the Python one.

It trains a small CNN on MNIST one sample at a time on an Arduino Nano 33 BLE Sense, with in-place layers and a 20-byte chunked serial protocol for FedAvg rounds with a Python server. NTU, 2025.
